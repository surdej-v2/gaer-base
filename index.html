Selvbetjening · QR · MobilePay

Sæt en QR-kode på varen. Kunden betaler selv.

Til gårdbutikken, kiosken uden personale, klubhuset eller standen ved vejen. Kunden scanner koden med telefonen, vælger antal og betaler med MobilePay. Ingen app, ingen login, ingen kasse. Du ser salget og lageret med det samme.

QR-koden åbner en side for netop den vare. Betalingen sker i MobilePay, og kunden kommer tilbage til en kvittering med ordrenummer.

Varer, QR-etiketter og ordrer ét sted

I administrationen på /admin/shop opretter du varer med pris og lager, udskriver etiketter og følger salget. Du logger ind med telefonnummer og passkey.

Indbygget

Det er der tænkt på

Ingen app eller login for kunden

En QR-kode og MobilePay. Det er det hele.

Ingen persondata

Ordrer gemmer vare, antal og beløb. Ikke navn, telefonnummer eller konto.

Pengene trækkes én gang

Betalingen hæves først, når MobilePay har godkendt den, og aldrig to gange.

Lager tælles ned

Udsolgte varer kan ikke købes, og kunden ser, hvor mange der er tilbage.

Alt bliver logget

Hver ændring af varer og ordrer står i audit-loggen, med hvem og hvornår.

Din egen server

Én container med egen database i Europa (OVHcloud). Intet sendes til andre end MobilePay.

Kom i gang

Til udvikleren

Butikken er bygget ind i Gær (Python/FastAPI, Vite/React, Postgres). Koden ligger i happy-mates-apps/gaer-self-service-shop, en fork af gaer-base.

  • /w/butik/<kode> er det, QR-koden åbner. /w/butik viser alle varer.
  • POST /api/public/shop/checkout opretter ordren og starter betalingen.
  • /w/butik/ordre/<token> er kvitteringen. Den spørger MobilePay om status og hæver beløbet.
  • /admin/shop og /admin/shop/print til varer, ordrer og etiketter.
  • Vipps MobilePay ePayment API: opret, status, capture. Lokalt giver PAYMENT_PROVIDER=console en testbetalingsside, som serveren afviser i produktion.
# Lokalt
git clone https://github.com/happy-mates-apps/gaer-self-service-shop
cd gaer-self-service-shop
docker compose up -d
(cd server && python -m app.migrate)
cd server && uvicorn app.main:app --reload \
  --port 8000 --env-file ../.env
npm run dev --prefix web

# Produktion (~/gaer/.env)
PAYMENT_PROVIDER=mobilepay
MOBILEPAY_API_URL=https://api.vipps.no
MOBILEPAY_CLIENT_ID=…
MOBILEPAY_CLIENT_SECRET=…
MOBILEPAY_SUBSCRIPTION_KEY=…
MOBILEPAY_MSN=…

Nøglerne kræver en aftale med Vipps MobilePay og findes i deres portal under API-nøgler. Prøv først mod testmiljøet med MOBILEPAY_API_URL=https://apitest.vipps.no.
