Åbn projektet i VS Code Desktop

Du er i Codespaces i browseren. Login, passkeys og den indbyggede browser virker kun rigtigt i VS Code Desktop, hvor appen kører på localhost.

Åbn i VS Code Desktop

Virker knappen ikke?

  1. Installer VS Code og udvidelsen GitHub Codespaces.
  2. Tryk F1 og vælg Codespaces: Open in VS Code Desktop.
  3. Eller gå til github.com/codespaces og vælg Open in › Visual Studio Code.
  4. Startsiden åbner igen derinde og skifter til appen, når den er klar.

Dev-stakken starter allerede i baggrunden, så den er klar, når du kommer ind.
